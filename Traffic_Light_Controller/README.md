# Traffic Light Controller in Verilog

## Features
- Moore Finite State Machine (FSM)
- Four-state traffic light sequencing
- Timer-based state transitions
- Asynchronous active-high reset
- Verilog testbench with waveform verification

## Tools Used
- Verilog HDL
- Icarus Verilog
- GTKWave
- Visual Studio Code
